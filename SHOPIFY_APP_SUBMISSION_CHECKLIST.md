# Shopify App Submission Checklist

## App Summary
- App Name: AI Chat Support
- Category: Customer Support / Chat
- App URL: https://ai-chat.support
- Privacy Policy: https://ai-chat.support/privacy
- Terms: https://ai-chat.support/terms
- Support: https://ai-chat.support/support

## Required Assets
- App icon (1024x1024)
- 3–6 screenshots (admin, widget, analytics)
- Optional video demo

## Technical Requirements
- OAuth flow working
- Webhooks registered and verified
- GDPR webhooks handled
- No use of protected customer data without approval
- Clear uninstall flow

## Functional Review
- Install/Uninstall verified
- Billing/credits explained
- No broken links in admin
- Widget loads over HTTPS on storefront

AI Chat Support adds a customizable chat widget to your Shopify store. It answers customer questions using verified data, supports order and product queries, and provides analytics insights. Setup is fast and designed for multi-tenant dashboards.
