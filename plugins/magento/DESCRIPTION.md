# AI Chat Support - Magento 2 Extension

Add the AI Chat Support widget to your Magento storefront in minutes. Configure your organization slug or ID in the admin panel and the widget loads automatically on every page. Designed for multi-store environments and lightweight by default.

## Key Features
- One-click enable/disable in Magento Admin
- Organization slug/ID configuration
- Store view support
- Fast, lightweight storefront injection

## External Dependency
- Widget script served from: https://ai-chat.support/widget/{org_slug}/script.js
