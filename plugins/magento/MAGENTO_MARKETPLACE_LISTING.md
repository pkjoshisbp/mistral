# Magento Marketplace Listing Copy (AI Chat Support)

## Extension Name
AI Chat Support – Chat Widget for Magento 2

## Short Description (max 255 chars)
Add AI Chat Support to your Magento storefront in minutes. Configure your org slug/ID in admin and the widget loads automatically on every page. Lightweight, fast, and multi-store compatible.

## Long Description
AI Chat Support helps Magento merchants convert more visitors and reduce support load with a fast, lightweight AI chat widget.

### Key Benefits
- **Simple setup**: Enable in Admin and add your organization slug/ID.
- **Works everywhere**: Injects on all storefront pages automatically.
- **Multi-store ready**: Configure per website/store view.
- **Lightweight**: Loads a single script, no heavy dependencies.

### How It Works
The extension injects a script tag that loads your AI Chat widget from:
https://ai-chat.support/widget/{org_slug}/script.js

### Requirements
- Magento 2.3+
- Admin access
- Active AI Chat Support organization slug/ID

### Support
- https://ai-chat.support
- support@ai-chat.support

## Installation (Marketplace/Composer)
1) composer require aichat/magento2-widget
2) php bin/magento setup:upgrade
3) php bin/magento cache:flush
4) Configure at Stores → Configuration → General → AI Chat Support
