# Privacy Disclosure (Magento Extension)

## Data Handling
- The extension does not store personal data in Magento.
- It injects a widget script from https://ai-chat.support.
- Chat data is processed by AI Chat Support outside Magento.

## Configuration Data
- Stores only org slug/ID and enabled flag in Magento system config.

## GDPR/CCPA
- No personal data stored in Magento by the extension.
- External processing occurs on AI Chat Support servers.
