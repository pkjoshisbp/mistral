# Privacy Policy (Marketplace Template)

## Overview
AI Chat Support for Magento injects a storefront chat widget by loading a script from https://ai-chat.support. The extension itself does not store personal data in Magento.

## Data Collected
- The Magento extension stores only configuration values (enabled flag and org slug/ID).
- Chat data is processed by AI Chat Support servers when visitors use the widget.

## Data Usage
- Chat data is used to respond to visitor questions and provide support context.
- No payment data or Magento customer records are accessed by this extension.

## Data Storage
- No personal data is stored in Magento by this extension.
- Chat data is stored and processed by AI Chat Support.
