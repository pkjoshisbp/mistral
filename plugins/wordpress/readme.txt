== Installation ==

**From WordPress Admin:**

1. Go to Plugins > Add New
2. Search for "AI Chat Support"
3. Install and activate the plugin
4. Go to AI Chat Support in your admin menu
5. Click "Register with AI Chat Support"
6. Configure your widget settings
7. Your AI chat widget is now live!

**Manual Installation:**

1. Download the plugin zip file
2. Upload to your `/wp-content/plugins/` directory
3. Activate the plugin through the 'Plugins' menu in WordPress
4. Follow the setup steps above
